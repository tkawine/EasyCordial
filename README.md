# EasyCordial
Cordial is a roblox client that runs Native Roblox by using the Android Builds, build entirely for Linux and always updated.
They are always working on fixes of bugs, and anything that can cause a glitch in the client, but... the topic is easy cordial right?
so.... whats **EasyCordial**?

EasyCordial is a cordial installer, that removes any type of glitch that can be caused by GPG verification, and by user mistyping or errors,
And Easy Cordial offers a easier way to install Cordial, by adding a Installer with GUI (Graphical User Interface) allowing a easier and
understandable process of installation of Cordial.
